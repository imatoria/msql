mSql — Premium SQL Query Repository

mSql is a modern, beautiful local web application designed to help developers and database administrators store, organize, search, and run SQL queries. With an offline-first architecture, all queries are kept entirely secure on your local machine.

Key Features

  • 100% Portability (Disk-First Storage): Queries are saved directly to your local file system as standard .sql files. No database configuration is required just to store your query files.
  • Embedded Portable Metadata: Metadata like titles, descriptions, tags, and creation dates are stored directly inside standard SQL comments at the top of each file. If you open files in other IDEs, they remain valid SQL.
  • Premium Developer UI: Built with a glassmorphism dark theme, smooth micro-animations, and responsive split-pane layouts for the editor and query results.
  • Live Search & Filtering: Quickly filter through hundreds of queries by tag badges or search keywords in real-time.
  • Rich SQL Code Editor: Equipped with line numbers, code highlighting, formatting shortcuts, and full tab key support.
  • Offline Demo Mode Fallback: If the backend server is unreachable (e.g. running statically on GitHub Pages), the app seamlessly switches to a simulated browser engine with sample data.

Installation & Setup

  1. Unzip the package to your preferred directory.
  2. Open your terminal in the directory and run:
    npm install
  3. Start the application server:
    npm start
  4. Open your browser and navigate to:
    http://localhost:3000

Metadata Comment Structure Example

-- Title: Active Users Report
-- Description: Retrieve a list of active users in the last 30 days.
-- Tags: users, analytics
-- Created: 2026-06-01
